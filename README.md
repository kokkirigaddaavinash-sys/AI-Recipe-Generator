# 🍳 AI Recipe Generator

An AI-powered recipe generator built using Flask and Google Gemini AI.

## ✨ Features

- Generate recipes using available ingredients
- AI-powered recipe generation
- Simple and beginner-friendly UI
- Shows ingredients, cooking steps and cooking time

## 🛠️ Technologies Used

- Python
- Flask
- Google Gemini AI
- HTML
- CSS
- JavaScript

## 🚀 How to Run

### 1. Clone the repository

git clone https://github.com/kokkirigaddaavinash-sys/AI-Recipe-Generator.git

### 2. Install dependencies

pip install -r requirements.txt

### 3. Add your Gemini API key

Create a `.env` file:

GEMINI_API_KEY=your_api_key_here

### 4. Run the application

python app.py

### 5. Open in browser

http://127.0.0.1:5000

## 📌 Project

This project was created as a learning project to understand Flask, APIs and Generative AI integration.
